# Bahins Auto Sales - Full Stack Commerce Platform
* WDD330 Final Project | BYU-Idaho

A custom-built vehicle management and listing platform designed to streamline operations for local car dealerships.

# Live Demo
[View Live Site](https://wdd330-final-project-bahins-auto-sales.onrender.com/)

# Tech Stack
* Frontend: JavaScript (ES6+), HTML5, CSS3
* Backend: Node.js 
* Deployment: Render

# Key Features
* Dynamic Inventory: Real-time rendering of vehicle listings from API.
* Search & Filter: llows users to filter vehicles by make, price, or year.
* Responsive Design: Fully optimized for mobile and desktop viewing.
* Admin Controls: Functional backend logic for managing vehicle data.

# Technical Challenges Solved
* **API Integration: Implemented custom REST API endpoints to fetch and display vehicle data.
* **State Management: Handled complex UI updates without page refreshes using modern JavaScript techniques.
* **Data Persistence: Ensured vehicle information is accurately stored and retrieved from the database.

# Installation & Setup
1. git clone https://github.com/bahintingchristopher/WDD330-Final-Project-Bahins-Auto-Sales
2. Install dependencies: `npm install`
3. Start the server: `npm start`
